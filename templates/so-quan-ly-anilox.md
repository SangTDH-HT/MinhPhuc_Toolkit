# SỔ QUẢN LÝ TRỤC ANILOX

Mỗi trục một dòng ở bảng 1, mỗi lần rửa/đo một dòng ở bảng 2. Nguồn hướng dẫn: Harper (skill `mp-in-flexo` → `muc-anilox-ban.md`).

## 1. Danh mục trục

| Số trục | Máy / trạm | Số dòng (LPI) | Thể tích danh định (BCM) | Ngày nhận | Nhà cung cấp | Dùng cho (mảng đặc / chữ / tram) |
|---|---|---|---|---|---|---|
| | | | | | | |

## 2. Rửa và đo thể tích

| Ngày | Số trục | Rửa (cách, dung dịch pH, nhiệt ≤ 49 °C) | Thể tích đo (BCM) | % so danh định | Xước, mẻ, bong gốm | Người |
|---|---|---|---|---|---|---|
| | | | | | | |

Gợi ý: thể tích giảm dần do nghẹt/mòn → màu nhạt, phủ không kín (FX-05). Đo định kỳ (gợi ý hằng quý) và sau mỗi lần rửa sâu.
Bàn chải inox (không đồng thau) · dung dịch pH 6,5–11,8 · khí nén khô không dầu · che bảo vệ khi không dùng · nhả dao gạt khi đổi màu.
