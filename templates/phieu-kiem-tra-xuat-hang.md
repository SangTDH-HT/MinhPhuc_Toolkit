## 1. Lấy mẫu (FEFCO / ISO 2859-1)

Cỡ lô N = …… → cỡ mẫu n = …… (`python -m mptinh aql --lo N --aql …`). Lấy rải đầu – giữa – cuối lô.

| Cấp lỗi | AQL | Số chấp nhận Ac | Số lỗi tìm thấy | Đạt |
|---|---|---|---|---|
| 1 — nghiêm trọng | 0 lỗi | 0 | | ☐ |
| 2A — nặng | 0,65 / 1,0 | | | ☐ |
| 2B — nặng (ít hơn) | 1,5 / 4,0 | | | ☐ |
| 3 — nhẹ | 6,5 | | | ☐ |

Một hộp nhiều lỗi chỉ tính lỗi nặng nhất. Hộp hỏng do vận chuyển không tính.
