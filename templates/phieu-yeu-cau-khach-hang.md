## 1. Năm thông tin bắt buộc

| Thông tin | Ghi |
|---|---|
| Kích thước **lọt lòng** D × R × C (mm) hoặc kích thước hàng + bao bì trong | |
| Hàng bên trong, **kg mỗi thùng** | |
| **Số lượng** mỗi lần đặt, tần suất | |
| **Nội dung in**: logo, số màu, mặt in, file | |
| **Nơi giao, ngày cần hàng** | |

## 2. Điều kiện dùng (để chọn kết cấu)

| Câu hỏi | Ghi |
|---|---|
| Xếp mấy tầng / chiều cao pallet | |
| Hàng có tự đỡ tải không (chai lon / điện tử có khoảng trống / hàng rời) | |
| Lưu kho bao lâu; kho lạnh/mát; đường biển | |
| Pallet bên nhận (1200×800, 1200×1000, 1100×1100…) | |
| Dựng thùng bằng máy tự động? | |
| Cần FSC? Tiếp xúc thực phẩm (món gì)? | |
| Thùng/hộp đang dùng (ảnh, mẫu) và vấn đề đang gặp | |
